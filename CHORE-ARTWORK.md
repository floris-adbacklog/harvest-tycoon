# Chore artwork

Six standalone illustrations generated with the built-in image generation tool.
Production files are 256 × 256 PNG images with the original transparent alpha,
in `public/assets/icons/chore-*.png`. The chore list and result dialog use the
same image for each activity. Interface labels remain in English.

## Generation prompts

Create ONE polished inventory icon for the cozy mobile farming game Harvest Tycoon: a small sturdy garden hand hoe with a honey-brown wooden handle and dark steel blade beside a freshly pulled clump of leafy green weeds with a few roots and a tiny clod of soil. Style: premium hand-painted 3D casual farming game item, softly faceted forms, warm amber highlights, rich sage and leaf greens, natural wood, subtle illustrated texture and soft ambient shading.
