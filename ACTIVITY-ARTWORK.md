# Farm activity artwork

Four standalone illustrations generated with the built-in image generation tool.
Production files are 256 × 256 PNGs with their transparent alpha preserved,
under `public/assets/icons/activity-*.png`. They appear on the farm markers,
in each job heading and in the farm-round tracker. Existing SVG controls remain
in place for navigation and for clear state differences within each mini-game.

## Generation prompts
